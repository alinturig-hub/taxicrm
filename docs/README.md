# TaxiCRM Documentation

## Overview

This directory contains the complete product documentation for TaxiCRM.

TaxiCRM is an AI-powered Operations Intelligence Platform for taxi companies.

The purpose of TaxiCRM is to collect operational data, transform it into business intelligence, and help company owners make better decisions.
